Run it on your own computer

Everything on the website works in your browser: drafting against the bots, sealed pools and the deck builder. Running a copy on your own computer adds the Live tab. It follows your MTG Arena drafts as you make them, shows PickNet's pick and the wheel odds for the pack in hand, and builds a deck from your pool. The website can't do that because browsers don't let websites read files on your computer, and Arena's log is a file on your computer.

What you need

  • Git, to download the site. On a Mac, run git --version in Terminal and it offers to install itself if it's missing. On Windows, get it from git-scm.com.
  • Python 3.8 or newer. You don't need any Python packages. Macs with the developer tools already have it (try python3 --version). On Windows, get it from python.org.
  • A recent browser. Chrome or Edge is fastest, because they let PickNet use several CPU threads.
  • About 150 MB of disk space. The download includes the models.
  • MTG Arena on the same computer, if you want the Live tab.

1. Download it

Open Terminal (Mac) or PowerShell (Windows), go to wherever you keep projects, and run:

git clone https://github.com/zscore/mtg-draft-sim-site.git
cd mtg-draft-sim-site

2. Start it

From the mtg-draft-sim-site folder:

python3 serve.py

On Windows, use py serve.py (or python serve.py). The command prints http://localhost:8000. Open that address in your browser. Leave the terminal window open while you use the site. Press Ctrl+C in the terminal to stop it.

Use serve.py, not a double-click on index.html. The page doesn't run from a file, and only serve.py can read Arena's log. If port 8000 is taken, pick another port: python3 serve.py 8001.

3. Turn on Arena's detailed logs

Arena only writes draft picks to its log when you ask it to. In Arena, go to Options → Account, tick Detailed Logs (Plugin Support), and restart Arena. You only do this once.

4. Draft

Reload http://localhost:8000 and a Live tab appears next to Draft and Sealed. Start a draft in Arena and it shows up there with every pack and pick. Older drafts are in the Draft menu: Arena keeps a few weeks of session logs. Click any pick in the table, or use Replay from pick 1, to step back through a draft with ← and →.

Where the drafts come from

The Logs menu on the Live tab picks the source:

Arena (live)
Arena's own logs. It follows the draft you're in, and lists older drafts from the session logs Arena keeps for a few weeks.
Archived logs
Copies kept by tools/archive_arena_logs.sh (below), for drafts older than Arena keeps.
Example logs, anonymized
Scrubbed logs that come with the download, to try the tab without Arena. They hold two finished draft pools but no picks, so they open on the pool and the deck builder. You still need Arena installed for the card names.
Choose a log file…
Opens your computer's file dialog, and follows whichever log you pick as it grows. Use it if Arena keeps its log somewhere unusual. The dialog can open behind the browser window.

Keep your old drafts (Mac, optional)

Arena replaces its main log every time it starts. To keep a copy of every session, run this once:

tools/archive_arena_logs.sh --install

It then copies the log into ~/mtga-log-archive every 15 minutes, in the background, and you'll find those drafts under Archived logs. To stop it, run tools/archive_arena_logs.sh --uninstall.

Updating

To get the latest version, stop the server, then run:

git pull
python3 serve.py

Always restart serve.py after updating. A server that's still running keeps serving the old version's Live features.

If something's wrong

There's no Live tab
The page isn't coming from serve.py. Open http://localhost:8000 while serve.py is running, not the file itself and not the website.
"No MTG Arena log found"
Arena's log isn't in the usual place. On a Mac that's ~/Library/Logs/Wizards Of The Coast/MTGA; on Windows it's %USERPROFILE%\AppData\LocalLow\Wizards Of The Coast\MTGA. Start the server with the folder you use, for example MTGA_LOG_DIR="/path/to/MTGA" python3 serve.py, or in PowerShell $env:MTGA_LOG_DIR="D:\path\to\MTGA"; py serve.py. You can also pick the log with Choose a log file….
"Detailed logs are off"
Turn on Detailed Logs (step 3) and restart Arena.
The cards have no names
The server can't find Arena's card database. Point it at the Raw_CardDatabase_*.mtga file in Arena's install folder with MTGA_CARD_DB, the same way as MTGA_LOG_DIR.
"Address already in use"
Another program, or another copy of serve.py, has port 8000. Stop it or use another port: python3 serve.py 8001.

Privacy

Your log stays on your computer. serve.py answers only requests from your own computer, and it only reads Arena's logs, the archive folder, and files you choose in its file dialog. The only thing the page fetches from the internet is card images, from Scryfall.
